# Para sua IA

Usa ChatGPT, Claude, Gemini, Cursor, Copilot ou outra IA para programar no Roblox? Envie este arquivo para ela. É **um único `.md`** com toda a API do SDK, as regras de validação, o que é automático, exemplos corretos e os erros mais comuns, escrito para modelos de linguagem.

Com ele a IA escreve integrações do RoMetrics certas de primeira, sem inventar funções.

## Como usar

- **Chat (ChatGPT, Claude, Gemini)**: clique em **Copiar tudo** e cole no começo da conversa, ou **Baixar .md** e anexe o arquivo.
- **Cursor / Windsurf / Copilot**: baixe e salve no projeto (ex.: `docs/rometrics-sdk.ai.md`) e referencie com `@rometrics-sdk.ai.md`. No Cursor dá para adicionar a URL em *Docs*.
- **Claude Code / agentes**: coloque o arquivo no repositório e cite no `CLAUDE.md` / `AGENTS.md`.
- **Ferramentas que leem `llms.txt`**: o índice está em [`/llms.txt`](/llms.txt).

Exemplo de pedido depois de enviar o arquivo:

> Integre o RoMetrics no meu jogo: inicialize com o Secret, conte as vendas do meu ProcessReceipt e registre um funil de tutorial com 4 passos.
